No feature is ever NaN/null/inf: not-applicable values use an out-of-range sentinel (-1, or -5 for the noise log-ratios) together with explicit flags. Column order is part of the contract. **Frozen model set: 79 features** (`similarity_features.FROZEN_MODEL_FEATURES`) = pair features + name-frequency features; context and retrieval features are computed on request only.
